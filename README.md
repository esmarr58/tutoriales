# Material de los videotutoriales · #tecnocircuito

Código, comandos y ejercicios para acompañar los videos de Rubén. Cada serie tiene su carpeta y cada episodio su propio material.

## Flutter y Dart en Ubuntu con VS Code

- [01 · Preparar el entorno para escritorio Linux](flutter-dart/01-entorno-ubuntu-2604/): instrucciones, comandos, proyecto del contador y reto.

## Qt Creator

- [01.a · Estructura de los archivos](qt-creator/01a-estructura-archivos/): complemento entre 01 y 02, ejemplo Hola mundo, mapa de archivos y reto.
- [Android · SDK y Hola mundo en el emulador](qt-creator/android-sdk-hola-mundo/): scripts, versiones, configuración de Qt Creator y ejemplo Qt Widgets.
- [Android y SQLite · 01–04](qt-creator/android-sqlite/): base SQLite en el teléfono; INSERT, consulta en QTableWidget y UPDATE, con las soluciones de los retos.
- [Qt y OpenCV · 02–06](qt-creator/opencv/): de QImage a cv::Mat, BGR contra RGB, leer un píxel con clic o toque, gris, brillo y contraste, e inspector de imágenes; mismo proyecto para escritorio y Android.

## Cómo descargar

Abre la carpeta del episodio para consultar comandos y código desde el navegador. En GitHub, selecciona **Code → Download ZIP** para descargar todos los ejemplos. También puedes clonar el repositorio:

```bash
git clone https://github.com/esmarr58/tutoriales.git
```

Lee el README de cada episodio para conocer las versiones y los pasos de ejecución. Los ejemplos no incluyen SDK, dependencias descargadas ni compilaciones. No necesitas una cuenta de GitHub para consultar o descargar estos archivos públicos.
